# LogBook_IVAO - Releases

Ce dépôt héberge uniquement les releases (installeur `.exe`) de **Tracker LogBook**, un outil de suivi de vol pour MSFS2020/X-PLANE/FSX avec ou sans IVAO/VATSIM intégré à la plateforme de Littoral Airlines.

Le code source est privé. Ce dépôt sert uniquement de point de téléchargement public pour l'installeur.

## Téléchargement

Voir la section [Releases](../../releases) pour la dernière version de `Tracker_Setup.exe` (installeur autonome, s'installe par défaut dans `C:\Tracker`).
