# Tracker - Releases

Ce dépôt héberge uniquement les releases (installeur `.exe`) de **Tracker LogBook**, un outil de suivi de vol pour MSFS2020/X-PLANE/FSX avec ou sans IVAO/VATSIM intégré à la plateforme de Littoral Airlines.

Niveaux d’utilisation
• Trois niveaux au choix  : 

-carnet de vol seul, avec alarmes temps réel, ou avec notation par l’IA. Le Tracker s’adapte à l’usage de chaque pilote.

-Historique des notes IA  : les notes /5 de chaque analyse sont archivées pour suivre sa
progression vol après vol.

-Analyse automatique au niveau 3  : le debrief IA se lance tout seul en fin de vol, sans question.

La documentation se trouve dans l'onglet "Aide" du tracker

Le code source est privé. Ce dépôt sert uniquement de point de téléchargement public pour l'installeur.

## Téléchargement

Voir la section [Releases](../../releases) pour la dernière version de `Tracker_Setup.exe` (installeur autonome, s'installe par défaut dans `C:\Tracker`).
