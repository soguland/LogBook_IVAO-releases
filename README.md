# LogBook_IVAO - Releases

Ce dépôt héberge uniquement les releases (installeurs `.msi`) de **Tracker LogBook**, un outil de suivi de vol pour MSFS2020/X-PLANE/FSX avec ou sans IVAO/VATSIM intégré à la plateforme de Littoral Airlines.

Le code source est privé. Ce dépôt sert uniquement de point de téléchargement public pour l'installeur.
